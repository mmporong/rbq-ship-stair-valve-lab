# T1 계단 학습 실패 장면

## T0 형상의 50°·19cm 목표 계단

종료 접촉이 검출된 5ms 물리 스텝의 상태를 MuJoCo 4.0에서 그렸다. 주황색은 충돌에 관여한 몸통 충돌체, 빨간색은 3단이다. 측면 시야를 위해 렌더링에서 양쪽 스트링어를 숨겼다.

- 7판은 0.35m/s 시행의 3.48초에 3단과 몸통 충돌을 기록했다. 해당 접촉의 힘 크기는 2,337N이다. [재생 장면](v7-target-50deg-body-tread3.png), [측정값](../../t1-v8-20261120/v7-target-50deg-route.json)
- 8판 9496은 0.5m/s 시행의 4.225초에 3단과 몸통 충돌을 기록했다. 해당 접촉의 힘 크기는 1,347N이다. [재생 장면](v8-9496-target-50deg-body-tread3.png), [측정값](../../t1-v8-20261120/v8-9496-target-50deg-route.json)
