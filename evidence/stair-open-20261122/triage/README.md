# RL Triage Agent의 RBQ 계단 적용성 시험

RL Triage Agent의 공식 준비 경로에 RBQ-10+RB1 8판 학습 로그를 넣었다. TensorBoard 스칼라 37개 그룹에서 근거 259개를 만들었고, NAT 1.9 설정과 의존성 검사는 통과했다. 외부 모델 호출, 검사 실행, 교정, GPU 학습은 수행하지 않았다. [준비 결과](agent-prepare/entry_report.json) · [전체 적용성 판정](assessment.json)

리포에 등록된 계단 적응은 표준 Go2가 높이 50mm·폭 300mm 계단을 0.25m/s로 내려가는 30초 개발 과제에 고정돼 있다. 저장된 전후 원시 trace 1,501행씩을 공식 판정기로 다시 계산했고, 전복 표본 888→0회와 속도 추종 RMSE 0.23285→0.06403m/s가 재현됐다. 검사 영수증, 모델 결정 계약, 호스트 승인 결합도 원본과 일치했다. 이 대조는 리포의 등록 경로가 보존됐음을 확인하며 RBQ 과제로 효과가 이전됐음을 뜻하지 않는다.

## RBQ 신규 CPU 평가

같은 50°·단 높이 190mm 계단, 같은 세 속도에서 7판과 8판의 동결 번들을 새로 재생했다. 이 자료의 `work_platform_reached`는 기존 왕복 평가기의 상부 플랫폼 도달 사건이다. 이번 밸브의 작업 위치는 앞발 5단·뒷발 3단이다. 두 정책 모두 가장 높이 지지한 발판이 1단이어서 그 작업 위치에도 도달하지 못했다.

| 정책 | 시행 | 상부 플랫폼 도달 | 지지한 최고 발판 | 종료 |
|---|---:|---:|---:|---|
| 7판 `model_8997.pt` | 3 | 0/3 | 세 시행 모두 1단 | 몸통과 3단 충돌 3/3 |
| 8판 `model_9496.pt` | 3 | 0/3 | 세 시행 모두 1단 | 몸통과 3단 충돌 3/3 |

8판의 전진 거리는 속도별로 7판보다 +8.7mm, +36.8mm, −35.5mm 달라졌다. 지지 발판과 작업 플랫폼 도달은 모두 변화가 없었다. 8판은 종료 벌점 변경을 사람이 정한 과거 실험이며 RL Triage Agent가 선택하거나 승인한 개입이 아니다. 이 비교를 에이전트 개선 효과로 세지 않는다. [7판 신규 재생](fresh-v7-route.json) · [8판 신규 재생](fresh-v8-route.json)

## 원래 저장소의 등록 범위

RBQ 학습 텔레메트리 수집과 공식 준비 경로는 작동했다. 원래 저장소에 등록된 검사는 RBQ의 50°·190mm 상승과 밸브 작업 자세를 다루지 않아 이 경로의 개입은 보류됐다.

원래 저장소 커밋 `81a2ff5`의 `tests/test_active_diagnosis.py`와 `tests/test_nemotron35_entry_v2.py`에서 38개 검사가 통과했다. 이 검사는 관측값 인용, 지원 범위 밖 결정의 보류, 모의 모델 응답을 사용한 NeMo Agent Toolkit 호출과 결과 기록을 확인한다.

로컬 `gemma3:4b`를 CPU 전용 `num_gpu=0`으로 한 번 호출해 별도 호스트 게이트도 확인했다. 모델은 지원 과제가 평지 표준 Go2이고 RBQ와 호환되지 않는다는 두 근거를 인용하면서도 `runtime_contact_window`를 골랐다. 호스트는 RBQ 사례가 등록 범위 밖이라는 계약에 따라 검사·승인·개입을 만들지 않고 `HOLD_without_execution`으로 닫았다. 이 결과는 로컬 모델과 JSON 계약의 연결 시험이며 공식 Nemotron 실행이나 진단 정확도 측정이 아니다. [사전 고정 계약](local-gemma-protocol.json) · [로컬 모델과 호스트 판정](local-gemma-result.json)

## RBQ 전용 어댑터에서 측정한 개입 효과

호스트 어댑터에서 8판 체크포인트 9100, 50° 계단, 성공 기준과 비교 조건을 고정했다. 로컬 Gemma가 원래 저장소의 근거 생성 함수를 통해 개발 조건 3개의 결과를 읽고 보행 위상을 25스텝 옮기는 설정을 선택했다. 개발에 사용하지 않은 시작 조건 6개를 무개입·사전에 정한 감속 규칙·모델 선택의 세 가지로 각각 실행했다. [선택 기록](rbq-host-ab-v1/agent-selection.json) · [고정한 비교 설계](rbq-host-ab-v1/protocol.json)

세 방법 모두 앞발 5단·뒷발 3단을 0.5초간 지지한 횟수가 0/6이었다. 무개입 대비 모델 선택의 평균 최고 지지 단은 1.17단에서 1.83단으로 올라갔고 전진 거리는 77mm 늘었다. 몸통 충돌은 4/6으로 같았고 최대 피치는 평균 6.28° 커졌다. 이 표본에서는 실제 작업 위치에 도달할 가능성이 높아졌다는 근거를 얻지 못했다. [18회 시행과 조건별 차이](rbq-host-ab-v1/README.md)
